# 星体模型资产

这些模型由仓库内的 `admin/scripts/build-celestial-models.mjs` 原创生成, 沿用仓库 MIT 许可证.
三份 GLB 均为真实三角形网格, 没有图片平面、外部 URI、纹理下载、压缩解码器或第三方资产依赖.
独立脉冲星不新增 GLB 文件, 由 `../pulsar/createPulsar.ts` 生成球面核心、封闭光束体积和磁场管线; 同样使用真实三维网格和场景资源作用域.

| 文件           | 内容                                                                      | 运行时用途                       |
| -------------- | ------------------------------------------------------------------------- | -------------------------------- |
| star.glb       | Surface 起伏球面、Corona 球形日冕壳                                       | 所有可用 Star 共享几何, 单独着色 |
| planet.glb     | Surface 简化岩质球面                                                      | 行星实例批次共享几何与材质       |
| black-hole.glb | Core 阴影代理、Horizon 光学球壳、Accretion 下的 Disc 连续盘体与 Glow 椭球 | black-hole 状态恒星的模型        |

在 `admin/` 使用已有 Node.js 和 Three.js 复现:

```text
node scripts/build-celestial-models.mjs
```

脚本只导出这三个本地文件, 不自动安装或请求网络. 修改生成器后先格式化脚本再生成, 不直接修改二进制资产.
几何、顶点色、透明渐变和节点名称写入 GLB; 运行时为恒星表面、日冕和黑洞光学体积替换程序化材质.
黑洞以 [NASA 的科学可视化](https://www.nasa.gov/universe/nasa-visualization-shows-a-black-holes-warped-world/) 为结构参考,
光学球壳内统一计算直接盘像、绕行盘像与捕获阴影. 它不是物理事件视界表面, 上下光带也不是固定竖直网格.
核心球面采用 128×96 分段, 盘体采用 256×40 分段; 光学球壳半径为 30, 光轨道冲量范围为 0.02..28.
盘体内缘为 `3 rs`, 约 5.196, 外缘为 24, 从 19.5 起衰减. 椭圆截面最大半厚度为 0.28, 与正侧视前景盘缘的局部体积采样一致.
Core 在运行时只负责射线拾取, Disc 与 Glow 保留离线建模结构但不重复栅格化; 避免用普通球体遮挡代替黑洞光学阴影.
光学材质按维护者选择为中央阴影加入很弱的球面明暗和轮廓光, 随观察角度变化并被前景盘像遮挡.
这是用于立体感的风格化着色, 不代表事件视界发光; 不改动 GLB 几何或增加独立核心绘制.
所有盘像共用同一流纹贴图、发射函数和差速流场; 模型姿态固定, 流纹为运行时生成的自有数据, 没有新增外部图片.
二维周期密度场在初始化时烘焙, 不以一维径向噪声重复形成同心条带; 亮结按实例时钟移动和消散.
流纹贴图 R 为近景细丝, G 为温差云团, B 为远景分段流团; 三者复用原有 RGBA8 纹理和采样.
远景流团在烘焙时筛选密度峰值并叠加角向断续和细层扰动, 同时保留过滤后的 R 通道能量, 随投影细节级别连续混合.
高温流在着色阶段使用增强的暖白发射, 外缘过渡为低饱和琥珀色; 配色与三倍展示时钟均不改动 GLB 资产.
实例绘制前绑定时间和局部相机位置, 场景内材质和纹理仍共享.
光轨道预计算思路参考 [Bruneton 2020](https://ebruneton.github.io/black_hole_shader/paper.pdf), 方程积分和着色实现由本项目独立编写.
轨道表覆盖捕获与逃逸光线, 以 RK4 生成; 有限距离相位和次像范围由轨道反求, 用于近景和亚像素覆盖过滤.
宽光弧在远景中仍保留实际盘面半径、发热梯度和盘缘; 整个节点的细节级别不用于替换它的形状.
没有复制或下载第三方着色器代码. 光学体积可从内部或外部观察, 不重复叠加双面表面. 没有独立发光线圈或全屏 Bloom.
光路角动量和圆轨道频率决定运动与引力频移, 两次交点共用同一发射模型; 极窄像使用预计算的径向发射积分校正能量.
这些仍是风格化实时模型: 临界阴影冲量为 4.5, 盘半径与屏幕冲量不是同一个量.
发射强度、显示色域和动画时间经过艺术调整, 弯曲盘像采用薄盘和前两次交点; 有限厚度只补充近侧视前景, 不是完整体积辐射转移.
写入节点附近的虚拟深度, 不沿弯曲光线与其它星体求交.
背景透镜采用屏幕空间颜色与深度近似, 不包含屏外或被遮挡的信息. 没有实现完整 Kerr 光线追踪、物理稳态吸积或完整环境光线追踪. 建模和加载代码可在以后替换为经过审核的美术资产,
但需保留节点名称契约和行星的实例化能力.

`celestialAssets.ts` 在创建 WebGL 画布前加载并校验模型, 所有 GPU 资源由场景作用域统一释放.
生产 Vite 构建自动打包资产并加内容哈希, 不需要手动复制到公共目录.
