# Verdandi Admin

> 2026-09-10 结构修订: 目标改为 Galaxy 包含 Peer 恒星, Relay 行星全量缓存 Galaxy 授权状态,
> 业务卫星可绑定恒星或行星. 详见 [共同星图架构](../galaxy-architecture.md).
> 下文和当前演示源码仍使用旧的业务行星模型, 本轮未实施展示迁移.

Verdandi Supervisor 的管理端基础工程, 使用 Vue 3、TypeScript、Vite、Naive UI 和 Three.js.
当前包含可折叠侧边栏与四恒星拓扑演示: Atlas、Lyra、Vega 保持可用, Orion 演示不可用状态,
三个可用节点共 144 个 Registry、Subscriber、Publisher 实体, 不可用 Orion 为独立黑洞.
所有连接和实体均为本地示例, 尚未接入 Supervisor API, 不代表真实集群状态.

## 本地运行

使用 Node.js 24 LTS 和 pnpm 12.3.4; `.node-version` 固定当前验证版本 24.21.0.
在 `admin/` 中运行:

```powershell
fnm use
pnpm dev
```

开发服务默认仅监听本机. 需要局域网访问时使用 `pnpm dev --host 0.0.0.0`.
首次运行前, 由维护者明确批准 `package.json` 中的具体依赖、来源和安装位置后, 才执行
`pnpm install --frozen-lockfile`. 依赖来自 npm 官方仓库, `node_modules/` 位于此目录.
pnpm store/cache 沿用用户配置; 当前工作站为 `D:\Program Data\pnpm\store` 和 `D:\Program Data\pnpm\cache`.
日常验证使用已有依赖, 不包含安装、更新、浏览器下载或发布步骤.

## 目录与扩展

```text
src/
  main.ts                      # 启动入口
  app/                         # 应用装配、布局、全局样式
  features/galaxy/
    index.ts                   # 功能公开入口
    model/                     # 只读展示契约、布局、快照校验
    data/                      # 本地演示快照
    ui/                        # 画布容器与行星详情
    composables/               # Vue 生命周期与异步场景加载
    runtime/                   # Three.js 场景、对象、输入、运动、帧调度
      assets/                  # 恒星、行星和黑洞 GLB 模型
      materials/               # 模型表面与日冕材质
scripts/                       # 离线检查工具与模型生成器
tests/                         # Node.js 回归测试
docs/                          # 架构说明与浏览器验收清单
```

`src/app/App.vue` 负责将 `demoGalaxy` 注入 `GalaxyView`. 渲染器不导入演示数据, 不请求 Supervisor API;
资产加载器仅按需读取随应用发布的同源 GLB 文件.
未来接入 API 时, 在数据适配层把网络 DTO 转成 `GalaxyData`, 再替换整个快照.
当前快照替换会重建场景并回到总览; 高频实时更新需要另行设计增量更新和背压.

参阅 [架构与生命周期](docs/architecture.md)、[贡献与代码规范](CONTRIBUTING.md)、[浏览器验收](docs/verification.md).
仓库总体规则仍以 [coding.md](../coding.md) 和 [codex.md](../codex.md) 为准.

## 已有交互

- 左键拖动旋转, 中键按住拖动平移, 滚轮围绕鼠标指向位置连续缩放.
- 旋转和平移每帧统一更新, 按时间阻尼平滑收敛; 按下指针立即接管相机, 聚焦前清除旧拖动惯性.
- 总览仅能选择恒星, 约 1.2 秒平滑推进且不打开详情; 进入星系后才能选择所属行星.
- 行星沿以恒星为焦点的椭圆公转, 近星段更快; 总览时间倍率为 5, 恒星视图为 2, 选中行星时全部暂停.
- 轨道在初始化时校验整个重复周期中的运动, 包含行星模型半径和安全间距; 可在不同时间经过同一区域, 不进行逐帧碰撞避让.
- 详情列表可切换实体, “推进至行星”接近公转后的实际位置.
- 选中后双击画布、在画布聚焦时按 Escape, 或关闭详情, 返回全局视图.
- 总览仅在右上角显示实际 FPS 数字, 无标题、轨迹、装饰星点或统计面板.
- Orion 只显示黑洞模型, 在星图中整体缩放为原模型的 75%, 不带行星、连线或 X 标记; 点击本体可以聚焦, 不打开行星详情.
- 页面隐藏时暂停绘制; 初始化或 WebGL 上下文失败时显示错误与重试入口.

## 性能边界

恒星表面和日冕按所属行星总数统一缩放, 倍率表示线性尺寸. 分段节点为:

| 行星数量 | <=10 | 30  | 60  | 120 | >=180 |
| -------- | ---- | --- | --- | --- | ----- |
| 大小倍率 | 0.5  | 1   | 1.5 | 2   | 3     |

节点间线性插值: 20→0.75、25→0.875、45→1.25、90→1.75、150→2.5. 所有实体类型合计计数,
当前 Atlas 36 颗为 1.1 倍、Lyra 48 颗为 1.3 倍、Vega 60 颗为 1.5 倍. 黑洞尺寸保持独立; 轨道规划会避开缩放后的恒星本体.
`GalaxyController.setStarRotationSpeed(peerId, radiansPerSecond)` 提供按恒星设置自转的接口, 默认 `2π/60` 弧度/秒, 即一分钟一圈,
暂不设数量、类型或选择状态驱动的速度规则. 正负速度分别沿本地 Y 轴正转和反转, 设置 0 停在当前姿态.
输入非有限值、节点不存在、节点不可用或场景已停止服务时返回 `false`; 重建快照后速度恢复默认值.
恒星表面和日冕同步转动, 使用已有帧增量; 选中行星仅暂停公转, 页面隐藏时整个场景暂停.

144 颗行星仍分为九个实例批次, 共享 GLB 几何、岩质纹理和材质. 每颗行星有独立的 Kepler 椭圆轨道,
生成时将周期选择为共同周期的整数分频, 同时调整半长轴以保持 Kepler 周期关系, 再筛选倾角与相位.
`Planet.position` 作为初始布局参考, 安全规划可能调整实际起点, 不改写快照. 全周期扫掠检查覆盖跨类型、跨星系和恒星本体,
采样间的曲线误差也计入包围半径. 初始化增加计算, 运行时仍只求椭圆位置; 检查数据在规划结束后释放.
极密集布局会有界扩大候选轨道范围; 搜索预算耗尽时报告初始化失败, 不退回有冲突的结果.
帧内复用计算缓冲, 每批上传一次实例矩阵; 当前规模合计约 9 KiB/帧, 暂停时不更新. 包围球覆盖完整轨道,
拾取、选中环和推进均读取当前实例位置. 大规模数据仍需另外评估计算与上传成本.
所有星体都从自有 GLB 加载, 每类模型在场景内共享, 不使用 Sprite 表现星体或日冕. 三份资产共约 1.3 MiB,
由 [离线模型生成器](scripts/build-celestial-models.mjs) 使用已有 Three.js 创建, 无第三方模型或贴图下载.
修改模型后运行 `node scripts/build-celestial-models.mjs`, 资产内容、所有权和复现方式见 [模型说明](src/features/galaxy/runtime/assets/README.md).
Three.js 和 GLB 均按需加载, 生产构建会为模型生成带内容哈希的文件名.
黑洞由 GLB 的封闭光学体积统一成像: 直接盘像、绕行盘像和捕获阴影使用相同的光路与前后遮挡.
盘内缘遵循非旋转黑洞的稳定圆轨道边界, 外盘延伸并渐暗; 发射与频移沿弯曲光路计算, 保留左右明暗差.
Core 网格保留点击拾取, Disc 与 Glow 保留离线建模结构; 运行时不重复绘制这些表面, 避免出现黑色半球和交叉双盘.
轨道表、有限距离观察相位、次像覆盖范围和带 mipmap 的流纹只在初始化时生成, 所有黑洞共享; 纹理数据约 2.35 MiB.
极细次像按像素覆盖面积过滤, 周期纹理接缝修正采样导数. 不进行全屏后处理或每帧数值轨道积分, 不增加独立帧循环.
流纹来自二维周期密度场, 内快外慢, 两个错开半周期的流场连续交替, 并加入逐渐生成、拉长和消散的局部亮结. 模型姿态不随流纹旋转.
流纹与亮结时钟以三倍速度推进, 相对上一版加速三倍; 周期内的最大剪切量保持不变, 行星速度独立.
远景使用分段流团并保留过滤后的细丝能量, 减少连续光滑亮带. 高温内缘与中心流采用更亮的暖白色, 外层过渡为低饱和琥珀色.
远景流团复用原贴图的 B 通道, 不增加贴图内存或纹理查询; 保留正常过滤并减少额外模糊.
中央黑色区域带有很弱的弧面层次和轮廓光, 随视角变化并受前景吸积盘遮挡; 这是经选择的美术表现, 不是事件视界真实发光.
近乎侧视时以四步局部体积采样补充前景盘缘厚度; 采样间距决定纹理过滤级别, 避免细纹变成闪动条码.
根据阴影在画面中的大小平滑降低亮结和纹理细节; 盘像保留真实交点, 仅对接近像素大小的细光环作覆盖近似.
黑洞仍为一次绘制, 每个实例在绘制前绑定动画参数和局部相机位置; 极窄像的发射积分在初始化时生成.
这是实时视觉模型: 使用非旋转黑洞光轨道, 只保留前两次盘面交点, 亮度与色域经过艺术调整; 场景遮挡采用节点附近的虚拟深度.
盘缘厚度是局部近似, 弯曲盘像仍采用薄盘; 没有实现环境星体折射、完整 Kerr 成像或物理吸积流体.
目标为 60 FPS, 像素比上限为 1.5; 实际帧率取决于 GPU、浏览器和显示刷新率, 此示例不构成大规模性能资格测试.
当前远程显示环境曾测得约 32 Hz 且浏览器使用软件渲染, 不能据此验证硬件渲染的 60 FPS 表现.
远程画面中的暗方块问题按用户要求暂缓处理.
